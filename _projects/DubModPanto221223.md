## Description
---
A live performance for Dublin Modular event - A very Dublin Modular PANTO!, presenting improvised music for guitar, modular synthesizer and laptop.

The performance explored the interaction between processed guitar, modular synthesis and real-time effects, with the laptop functioning as a live mixing environment.
